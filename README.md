# Linlo
Linlo is a free, flexible Bash-based filesystem search utility that makes finding files and directories from your terminal simple. Search your system by name, filter results by files or directories, and choose between partial and exact-name matching. Includes command-line search, OS and distribution detection, system information, version reporting, and built-in help. Supports Linux, FreeBSD, and macOS. Requires `findutils`.

You can view the previous archives here: https://sites.google.com/view/linlofilefinder/downloads
